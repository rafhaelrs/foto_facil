# 📸 Sara Foto Fácil - Conversor de Fotos (PWA)

Aplicativo leve, intuitivo e moderno desenvolvido especialmente para converter fotos de alta qualidade (inclusive formato `.HEIC` do iPhone, `.WEBP` e fotos de câmeras) para `.JPG` e `.PNG`.

---

## ✨ Características Principais

- **Visual Idêntico no Celular e Notebook:** A mesma tela simples, os mesmos botões, sem confusão.
- **100% Privado e Seguro:** Todo o processamento é feito na memória do aparelho. Nenhuma foto é enviada para a internet.
- **Leve para aparelhos antigos:** Processamento sequencial otimizado que não consome excesso de memória RAM nem trava celulares/computadores modestos.
- **Conversão em Lote e Download em .ZIP:** Converte 1 ou dezenas de fotos de uma vez e permite baixar tudo empacotado em um único clique.
- **Suporte Offline (PWA):** Após o primeiro carregamento, funciona mesmo se estiver sem conexão com a internet.

## 🚀 Como Publicar no GitHub Pages (Passo a Passo)

### 1. Crie o Repositório no GitHub
1. Acesse o seu GitHub ([github.com](https://github.com/)) e clique em **New repository** (Novo repositório).
2. Dê o nome de `sara-foto-facil`.
3. Deixe como **Public** (necessário para GitHub Pages gratuito).
4. **Não marque** as opções de adicionar README ou .gitignore (os arquivos já estão prontos aqui).
5. Clique em **Create repository**.

### 2. Envie os Arquivos do seu Computador
No terminal da pasta deste projeto (`c:\Rafhael\OpenCode\rrs\sara-foto-facil`), execute:

```bash
git remote add origin https://github.com/SEU_USUARIO/sara-foto-facil.git
git branch -M main
git push -u origin main
```
*(Substitua `SEU_USUARIO` pelo seu nome de usuário no GitHub)*

### 3. Ative o GitHub Pages
1. No seu repositório no GitHub, clique na aba **Settings** (Configurações).
2. No menu lateral esquerdo, clique em **Pages**.
3. Em **Build and deployment** $\rightarrow$ **Branch**, selecione `main` e a pasta `/(root)`.
4. Clique em **Save**.
5. Aguarde cerca de 1 a 2 minutos. O GitHub exibirá o link final:
   👉 `https://SEU_USUARIO.github.io/sara-foto-facil/`

## 📲 Como Instalar para a Sara usar

### No Celular (Android)
1. Abra o link gerado no **Google Chrome**.
2. Aparecerá uma barra roxa no topo: **"Instalar Aplicativo"**. Basta clicar em **Instalar**.
   *(Ou toque nos 3 pontinhos do Chrome $\rightarrow$ "Adicionar à tela inicial" / "Instalar aplicativo")*.
3. O ícone **Sara Foto Fácil** ficará na tela inicial como qualquer app normal!

### No Celular (iPhone / iPad)
1. Abra o link no **Safari**.
2. Toque no botão de **Compartilhar** (ícone de um quadrado com uma setinha para cima ⎋ na barra inferior).
3. Role um pouco para baixo e toque em **"Adicionar à Tela de Início"** (➕).
4. Toque em **Adicionar** no canto superior direito.
5. Pronto! O ícone aparece junto aos outros apps dela.

### No Notebook (Windows - Chrome ou Edge)
1. Abra o link no **Google Chrome** ou **Microsoft Edge**.
2. No topo da página haverá o botão **Instalar** (ou na barra de endereços, perto da estrela de favoritos, haverá um ícone de monitor com uma setinha).
3. Clique em **Instalar**.
4. O Windows criará um atalho próprio na **Área de Trabalho** e no **Menu Iniciar**.
5. Ao abrir, ele roda em uma janela própria, sem barra de abas ou cara de site, parecendo um programa instalado normal!
